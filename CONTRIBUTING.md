# Contributing

This is Andrew Hingston's project, not currently seeking PRs, but notes for anyone
building on it:

- Engine changes: `engine/` is Rust, edition 2024. Build with
  `cargo build --release` in `engine/`; the binary lands at
  `engine/target/release/peanut`. Read `docs/ARCHITECTURE.md` first — the crate is
  small (six modules) but the invariants (digit order, zero-closure after every
  `exists`, the memory budget) are load-bearing.
- Never launch the engine binary directly from a script, and never run several
  engine processes in parallel outside `explore/engine.py`. Read `docs/GUARD.md`
  before touching anything that spawns processes.
- Formula/command additions: extend `engine/src/logic.rs` (parser + compiler) and/or
  `engine/src/main.rs` (stdin command dispatch), then update `docs/COMMANDS.md` to
  match exactly — that file is meant to be generated by reading the source, not by
  memory.
- GUI changes: `gui/serve.py` launches every engine process through
  `explore/engine.py` — do not bypass it. See `gui/DESIGN.md` for the front-end
  conventions and `brand/BRAND.md` for the mascot/palette.

  licensed under the same terms.

## Issues / questions

Open a GitHub issue. For anything involving the research result the engine was built
to answer, see the README's "Results" section.
