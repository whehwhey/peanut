Peanut

A decision procedure for automatic sequences, with a mascot.

Peanut is a first-order-logic decision procedure for k-automatic sequences. Give it a morphism and a coding, and it compiles sentences over <N, +, <, V_k> and the resulting sequence into deterministic finite automata; the compilation is the proof. It answers exactly, for all n at once, questions that a computer could otherwise only sample. On top of that core sits an adaptive determinization ladder for hard predicates, a guess-and-verify active-learning construction for the notoriously expensive "equality of factors" predicate, a hard resource guard so a bad query fails safely instead of eating the machine, and a browser GUI.

Install and run

One command, needs Rust and Python 3:

git clone https://github.com/whehwhey/peanut.git
cd peanut
./start.sh

This builds the engine if needed, starts the web GUI, and opens your browser. For the command-line engine directly: 

cd engine && cargo build --release
echo 'mode msd
def T 2 2 0 01 10 01
? A i. T[i]=T[i]
quit' | ./target/release/peanut

What it is for

Peanut exists to answer questions about automatic sequences that other tools choke on, in particular Mazen Khodier's open problem about the "equality of factors" predicate, whose direct construction is documented to blow up by nine orders of magnitude on Tribonacci before collapsing to a 26-state minimal answer. See the Results page for what Peanut has been used to prove, and Benchmarks for how it compares to Walnut.
